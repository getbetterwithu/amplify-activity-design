# 화면 카드 카탈로그 색인

- 카탈로그 공개 페이지: (선생님이 만든 뒤 적는다. 활동 주소는 적지 않는다)
- 썸네일: `assets/catalog/카드번호.jpg` (가로 약 360px JPEG). 학교·학생 정보와 교과서 그림이 들어가지 않았는지 확인한 것만 넣는다.
- 카탈로그 판: v1 (카탈로그 쪽 번호가 바뀌면 판 번호를 올리고 이 표와 썸네일을 함께 다시 맞춘다)
