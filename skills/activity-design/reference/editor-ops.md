# Amplify 편집기 조작 절차

편집기를 직접 조작하며 저장값으로 확인한 절차다. **내부 API·클래스 이름은 Amplify가 바꿀 수 있다.** 동작하지 않으면 이 문서를 믿지 말고 화면을 다시 살피고, 바뀐 점을 알려 준다. 한국어 화면(`?lang=ko`) 기준이다.

## 0. 작업 전 안전
- 같은 액티비티 편집기는 **탭 하나만** 연다. 두 탭에서 편집하면 꼬여서 작업이 날아갈 수 있다. 사용자가 연 탭에서 작업한다.
- **편집기를 열기 전에 로그인 상태와 계정을 확인한다.** 로그인이 안 되어 있으면 멈추고 교사에게 로그인을 부탁한다. 비밀번호를 대신 입력하지 않는다. 다른 계정으로 로그인되어 있으면 멈추고 알린다(다른 계정에 만든 활동은 옮기기 어렵다).
- **사용자 탭의 창 크기(viewport)는 함부로 바꾸지 않는다.** 조작이 가려지면 먼저 대상을 화면 안으로 굴리거나 카드·창 위치를 옮긴다. 배율 조정은 마지막 수단이며(사이트별로 기억되어 사용자 탭에 남는다), 바꿨으면 작업 뒤 되돌리고 되돌렸는지 확인한다(`lint.md` 2-1절).
- 사용자 탭이 예전 상태이면 새로고침(Cmd+R) 뒤에 작업한다. 작업 뒤에는 미리보기 창을 닫는다.
- 쓰기(입력·삭제·이동·저장)는 사용자의 명시적 지시 뒤에만 한다.
- **모든 변경은 저장값으로 확인한다**(다음 절). 화면에 그렇게 보이는 것만으로 끝내지 않는다.

## 1. 읽기·확인 (활동을 바꾸지 않는다)
- 편집기에서 `window.__dc_resources.lessonQuery.listScreens({includeHiddenScreens:true})` → 화면 배열. 여기서 확인할 수 있는 것: 화면 순서, 각 화면의 `root.linearlayout` 구성요소 순서, 메모 doc(heading, color mark, `mq` 수식 노드), 교사 팁 `teacherTips["teacher-moves"]`, 객관식 `answerKey`, 그래프 `calculatorState`, CL `script`, 이미지 `allowFullscreen`. (확인됨)
- 구성요소 키: `input/graph`, `exhibit/text`, `exhibit/image`, `input/text`, `input/expression`, `polypad`, `sketch`, `cardsort`, `multiple-choice`, `table`, `action-button`.
- **수식 밖에 남은 글자 검사:** 메모 doc과 교사 팁(`teacherTips["teacher-moves"].content`)을 돌며 `mq` 노드는 건너뛰고, 나머지 text에 `\\`(LaTeX 원문)이나 수식 꼴이 있으면 목록으로 뽑는다. `mq` 노드 안의 text까지 검사하면 정상 수식도 걸리므로 반드시 건너뛴다. 저장할 때마다 `lint.md`의 점검 스크립트로 돌리고 결과를 보여 준다. (확인됨)
- **사용자가 고친 화면을 다시 만질 때는 먼저 저장값을 읽어 내가 넣은 값과의 차이(라벨 글자·크기·위치, 보기 범위, 배치, 문장)를 정리한다.** 그 값을 기준본으로 두고 되돌리지 않는다.

## 2. 화면
- **새 방법의 시험은 원본 화면이 아니라 복사본에서 한다.**
  1. 시험할 구성요소가 있는 화면을 「화면 복사」한다. 복사본은 구성요소 이름이 원본과 같으므로, 다른 구성요소를 참조하는 CL이 없는 화면을 고르거나 복사 직후 이름을 바꾼다.
  2. 복사본에서만 시험하고, 저장값과 학생 미리보기로 결과를 확인한다.
  3. 복사본의 화면 id를 다시 확인한 뒤 「화면 삭제」로 지운다.
  4. 화면 목록이 시험 전과 같은지, 원본 화면에 시험 흔적이 없는지 저장값으로 확인한다.
- **새 화면:** 화면 선택 → 「새 화면」(선택한 화면 바로 뒤에 생긴다).
- **화면 복사:** 화면 선택 → 왼쪽 위 「옵션 더 보기」 → 「화면 복사」(바로 뒤에 생기고 교사 팁도 복사된다. 교사 팁은 반드시 고친다).
- **화면 삭제:** 화면 리스트 썸네일의 X(`[role=option] .delete-button`) → 「화면 삭제」. **삭제 전에 화면 id로 대상을 확인한다.**
- **화면 제목:** `textbox "화면 제목 또는 소개:"`.
- **화면 스크립트(부제 등):** 「스크립트 열기」 → 코드 클릭 → Meta+A → `insertText('subtitle: "…"')` → 「완료」.
- **화면 순서 바꾸기:** 화면 리스트의 썸네일을 마우스로 누른 채 목표 자리까지 천천히 끌어 놓는다. 끝난 뒤 저장값으로 순서를 확인한다. (확인됨)
- **화면 삭제 전 백업:** Amplify에는 화면 휴지통이 없다. 지우기 전에 `listScreens` 결과에서 그 화면 JSON을 파일로 남기고, 여러 개를 지울 때는 뒤에서부터 하나씩 지우며 매번 id를 확인한다. 화면 옵션 메뉴(「옵션 더 보기」 → 「화면 삭제」 → 확인 창 「화면 삭제」)로도 지울 수 있다. (확인됨)
- **화면 제목**은 저장값에서 화면 객체의 `title`로 남는다.

## 3. 구성요소
- **추가:** 왼쪽 목록 버튼(메모·표·객관식 문제·자유 답변·미디어 …)을 누르면 화면 끝에 붙는다. 미디어가 있으면 자동으로 두 칸이 된다(왼쪽 이미지, 오른쪽 나머지).
- **이동:** 「… 핸들입니다. 방향키로 조정하세요.」 버튼에 focus → ArrowUp/Down(한 칸), ArrowLeft/Right(칸 이동). **한 번 누를 때마다 저장값으로 순서를 확인한다**(예상과 다른 자리로 갈 수 있다).
- **삭제:** 「…」(Open More Component Options) → 「구성 요소 삭제」. 자동화할 때 글자가 「구성 요소 삭제」인 요소를 찾으면 「…」 버튼 자신이 먼저 잡힐 수 있다. 너비가 넓은 메뉴 항목(span)을 골라 누르고, 저장값에서 구성요소가 사라졌는지 확인한다. 지우기 전에 화면 JSON을 백업한다. (확인됨)
- **다른 화면으로 복사:** 「구성 요소 복사」 → 대상 화면의 빈 곳 클릭 → Meta+V (Polypad 설정까지 그대로 온다). 그래프는 식·설정·CL까지 함께 온다. 붙인 뒤 이름을 바꾸고 CL이 가리키는 이름도 고친다. (확인됨)
- **새 구성요소의 위치:**
- **그래프·미디어가 없는 화면도 두 열로 만들 수 있다.** 구성요소 핸들에 포커스를 두고 오른쪽 방향키를 누르면 오른쪽 열이 생기고 그 구성요소가 옮겨진다. 한 번 누를 때마다 저장값으로 순서를 확인한다. (1회 관찰) 지금 포커스가 있는 구성요소 근처에 생긴다. 그래프가 먼저 있으면 나머지는 자동으로 오른쪽 열에 붙는다. 추가한 뒤 이동 절차로 자리를 맞춘다. 이동은 핸들에 포커스 → Space로 잡기 → 방향키 → Space로 놓기.
- 숨김(`hidden`) 상태인 구성요소도 편집기에서는 보인다. 삭제는 그 구성요소 안의 「⋯」 → 「구성 요소 삭제」.

### 3-1. 표
- **표를 만들기 전에 열 수부터 센다.** 이름 열을 포함해 두 열 화면 5열 이상, 한 열 화면 7열 이상이면 행열을 뒤바꿔 세로 표로 만든다(`design-rules.md` 2절).
- **열 추가:** 머리글 칸 옆 「옵션 더 보기」 → 「오른쪽(왼쪽)에 열 삽입」. 같은 메뉴의 「텍스트로 구성」은 그 열을 글 칸(고정 글, 예: 방법 이름)으로 바꾼다. (저장값 `columnTypes` 확인)
- **행 추가:** 마지막 빈 행의 칸을 클릭하면 행이 생긴다(별도 단추는 없다). (확인됨)
- 편집기에서 글을 쓴 칸은 학생에게 잠긴 칸이 된다(「입력한 셀 잠금」 기본 켜짐).
- **헤더와 셀 좌표:** 표 옵션 「헤더」에 「상단」「왼쪽」이 있고 기본은 상단 고정이다. 헤더는 셀 좌표에서 빠진다. 상단만 헤더면 `cellContent(2,1)`은 헤더를 뺀 2행 1열, 곧 화면상 세 번째 줄이다. (확인됨) 왼쪽 헤더도 같은 방식으로 열에서 빠지고, 헤더를 해제하면 첫 행·첫 열부터 좌표에 들어간다. (미확인) CL에서 셀 좌표를 쓰기 전에 헤더 설정부터 확인한다.
- **특정 셀만 잠그기:** 표 CL에 `cellEditable(행,열): false`. 「입력한 셀 잠금」은 교사가 글을 쓴 칸 전체를 잠근다. 「학생이 행을 추가」 옵션은 필요할 때만 켠다. (미확인)

## 4. 메모 서식 (큰 글씨·글자색)
- 메모 칸 클릭 → Meta+A → `ClipboardEvent('paste')`에 `text/html`(`<h2>`, `<p>`, `<span style="color:#hex">`)과 `text/plain`을 넣으면 큰 글씨와 색이 저장된다.
- **Shift+Enter 줄바꿈은 안 먹고 글자가 붙는다**(「확률은많은」). 문단(`<p>` 또는 Enter)으로 나눈다.
- **이미 쓴 글의 일부에만 색을 넣기(전체를 다시 붙이지 않는다):** 칠할 구절만 DOM Range로 선택 → 붙여넣기 이벤트에 그 구절의 `<strong><span style="color:#hex">구절</span></strong>`을 넣는다. 그 부분만 색·굵게가 되고 나머지 글과 수식은 그대로다. 색을 지울 때는 같은 구절을 태그 없이 붙여 넣는다. 조사까지 칠해졌으면 「조사 + 색 구절」로 다시 붙인다. (확인됨)
- 문단 하나를 지울 때는 앞 문단 끝 뒤부터 지울 문단 끝까지 Range로 잡고 Backspace.
- 미리보기 창이 열린 채 입력하면 반영되지 않는다 → 먼저 「대화창 닫기」.
- **표 머리글은 글자만 저장된다**(색 불가). 표 안 색 구분이 필요하면 표 밖 메모로 한다.

## 5. 수식으로 바꾸기
- 메모·선택지·교사 팁 편집기에서 글자를 선택하고 백틱(`` ` ``)을 누르면 수식이 된다(doc의 `mq` 노드, 선택지는 문자열 안 백틱).
- 자동화: DOM Range로 선택 → `selectionchange` 이벤트 → 0.4초 대기 → `Backquote` 키.
- 「1/2」를 그냥 바꾸면 빗금 수식이 된다 → 수식 칸 안에서 지우고 키보드로 `1/2`를 다시 치면 `\frac{1}{2}`가 된다.
- 이미 수식인 글자는 `[class*="mq-"]` 조상으로 걸러야 다시 잡지 않는다.
- **이미 있는 수식을 바꾸기(예: `A` → `\mathrm{A}`):** 문단(p/h) 바로 아래의 수식 감싸개 요소 앞뒤로 Range를 잡고(`setStartBefore`/`setEndAfter`) 새 LaTeX 글자를 넣은 뒤, 그 글자를 선택하고 백틱. 색이 있던 수식이면 색 span으로 붙여 넣은 뒤 백틱하면 수식에 색 표시가 유지된다. 미리보기 읽기 이름에서 `"A"`(따옴표)는 기울임, `A`는 `\mathrm`이다. (확인됨)
- **수식 안 띄어쓰기는 스페이스바(Space)**를 누른다(`\ `로 저장된다). **백슬래시+공백을 직접 타이핑하면 `\backslash` 글자가 들어가므로 금지.**
- 여러 수식 조각을 하나로 합치기: DOM Range로 첫 수식 뒤부터 마지막 수식 끝까지 지정(`setStartAfter`/`setEndAfter`, 감싸개는 p/h 바로 아래 요소) → Backspace → 한 수식으로 다시 입력.
- 수식 문법은 `math-notation.md`를 따른다.
- **여러 수식을 한꺼번에 넣기(교사 팁에서 확인):** 글을 붙여넣을 때 수식 자리를 `⟦…⟧`로 표시해 두고, 뒤에서부터 하나씩 선택 → Backspace → 백틱 → 내용 타이핑 → Escape. 분수는 수식 칸에서 `/`를 먼저 치고 분자 → ↓ → 분모. (확인됨)
- **백슬래시 명령을 타이핑하면 `\backslash`가 된다**(`\times`, `\le` 등). 곱셈은 `×` 문자를 수식 칸에 넣고, 부등호는 `<=`로 친다(≤로 바뀜). (확인됨)
- `<`가 든 글을 HTML로 붙여넣으면 그 뒤가 잘린다. `&lt;`로 쓰거나 text/plain으로 넣는다.
- 화면 썸네일에도 같은 글자의 편집기 복사본이 있다. 글자로 편집기를 찾을 때는 `contenteditable="true"`인 쪽만 고른다.

## 6. 객관식·체크박스
- 선택지 칸 + 「선택지 추가」. 정답을 표시한 뒤 저장값 `answerKey`를 확인한다. 「…」 → 「무작위 선택지 순서」. 체크박스는 객관식의 다중 선택(multi)이다.
- 정답은 선택지 옆 「정답」 라벨을 누른다(라디오·체크박스는 숨겨져 있어 라벨 영역을 눌러야 한다). 체크박스는 정답이 여러 개(`c-1`, `c-3`)로 저장된다. (확인됨)
- 「⋯」 메뉴: 「다음으로 변환」(객관식 ↔ 체크박스), 설정(무작위 순서, 글자 번호, 처음부터 체크), 레이아웃(객관식: 라디오 버튼/기본 버튼/토글 버튼/타일, 체크박스: 체크박스/기본 버튼/타일). 저장값 `choiceLayout`.
- 선택지 글에도 수식(백틱)을 넣을 수 있다.

## 7. 이미지
- **미디어 이미지:** `input[type=file][accept*="image/png"]`에 `setInputFiles`. 「이미지 설명:」에 대체 텍스트. 「…」 → **「테두리 표시」**(저장값 `showBorder: true`, 주변 글과 구별되어야 하면 기본으로 켠다), **「전체 화면 허용」**(저장값 `allowFullscreen: true`, 미리보기에 확대 아이콘).
- **그림판 배경:** 「배경」 → `input[type=file][accept="image/*"]`.
- **Polypad 이미지 교체:** 사이드바 설정 → 「작성 모드」 켜기 → 기존 이미지 클릭 → 액션 바 4번째(삭제) → 툴바 「이미지 업로드」(filechooser) → 새 이미지 클릭 → 액션 바 5번째 → 너비 입력 → 「저작」에서 위치, 「상호 작용」에서 잠김 → 작성 모드 끄기.
- **대표 이미지(썸네일):** 편집기 상단 제목 버튼(「액티비티 정보 편집」) → 정보 창 왼쪽 정사각형 칸 → 창 안의 `input[type=file][accept="image/*"]`에 `setInputFiles` → 「저장」. 같은 창에 과목·학년, 익명 동물 이름 체크, 공유 설정(링크/비공개), 액티비티 설명, Activity Style이 있다. **(1회 관찰)** 「취소」 → 「Unsaved Changes」 → 확인으로 버려도 업로드한 이미지는 남아 있었다.

## 8. 그래프 구성요소의 식
- 「그래프 편집」 창을 연 뒤 `Desmos.getCalcByElement(넓은 div.calculator.calculator__graphing)`로 계산기를 얻는다. `setExpression({id, latex, color, label, showLabel, labelOrientation, lineStyle})`, `updateSettings({xAxisLabel, yAxisLabel})`, `setMathBounds`로 설정하고 「완료」. 값 검증은 `HelperExpression`.
- 라벨은 `${변수}` 보간을 쓸 수 있다. 오른쪽 끝 점의 라벨은 `labelOrientation: 'above_left'`로 해야 잘리지 않는다.
- **그래프 편집 창을 열면 계산기가 두 개 잡힌다.** 식 항목(`.dcg-expressionitem`)이 있는 쪽(편집 창 안)을 골라야 저장된다. 다른 쪽을 바꾸면 저장되지 않는다. 창을 열 때마다 다시 확인한다. (확인됨)
- **슬라이더 범위**는 `setExpression`의 `slider` 옵션으로는 저장되지 않는다. `getState()`로 받아 식의 `slider{hardMin, hardMax, min, max, step}`을 고친 뒤 `setState`한다. 같은 방식으로 `colorLatex`(색 변수)도 넣는다. (확인됨)
- **자신이 만든** 다른 활동의 그래프 상태는 활동 데이터(읽기 전용)에서 읽어 `setState`로 통째로 옮길 수 있다. 저장된 상태로 되돌릴 때도 같다. (확인됨)
- 저장 전에 시험용으로 바꾼 값(슬라이더, 기록 목록, 숨긴 변수)을 시작값으로 되돌린다. 편집 창에서 바꾼 범위(`setMathBounds`)는 학생 화면 범위가 된다.
- 복사한 그래프에 지운 변수를 참조하는 라벨(`${a}` 등)이 남으면 「정의되지 않음」이 뜬다. `calc.expressionAnalysis`의 오류 항목으로 찾는다. 읽기만 할 때는 「변경 사항 취소」로 닫는다.
- 그래프 라벨은 굵게가 안 된다(크기·색·띠·상자로 강조). 변수 이름 `e`는 상수라 쓸 수 없다.
- **확인하지 않은 설정 값을 넣지 않는다.** 라벨 크기는 숫자(`labelSize: '1.3'`, `'2'` 등)로 쓰고 `large` 같은 이름 값을 쓰지 않는다. 모르는 설정은 사용자에게 묻는다.
- **점 이름 라벨은 기본 크기보다 키운다**(예: `labelSize: '2'`). 기본 크기로 두면 그림 안에서 이름이 작아 거의 매번 고치게 된다. 점 이름은 `` `\mathrm{A}` ``처럼 백틱 수식으로 쓰고, 이름끼리 겹치지 않게 `labelOrientation`을 점마다 정한다.
- **좌표는 반올림해서 넣는다.** `Math.cos` 결과의 `5.2e-17` 같은 지수 표기는 그래프 식에서 `5.2×e−17`로 읽혀 점이 화면 밖으로 튄다. 소수 6자리로 반올림하고 0에 가까우면 `0`으로 쓴다. (확인됨)
- **선분 함수 `\operatorname{segment}`는 Amplify 그래프에서 지원되지 않는다**(「이 계산기는 'segment' 기능을 지원하지 않습니다」). 선분은 `(x_1+(x_2-x_1)t,\ y_1+(y_2-y_1)t)\{0\le t\le1\}`로 그리고 점선은 `lineStyle: 'DASHED'`. 식을 넣은 뒤 `calc.expressionAnalysis`로 오류를 확인한다. (확인됨)
- 칸이 있는 그림(전개도·격자)은 보기 범위의 가로·세로 비율을 그림판 비율(정사각형 480×480 등)에 맞춰 칸이 정사각형으로 보이게 한다. 면 다각형과 테두리 다각형(채우기 0)을 따로 두면 선 종류를 나눠 그릴 수 있다.
- **라벨만 보이는 점은 `pointOpacity`가 아니라 `pointSize: '0'`으로 숨긴다.** `pointOpacity: '0'`이면 라벨도 함께 사라진다. (1회 관찰)
- 라벨에 백틱 수식과 `${}`를 함께 쓸 수 있다(예: `` `y=x^2-${n}` ``). (1회 관찰)
- 보기 범위는 `setState`의 viewport만으로는 저장되지 않을 때가 있다. 「완료」를 누르기 직전에 `setMathBounds`로 다시 넣고 저장값으로 확인한다. (1회 관찰)
- **CL `function("g")`로 받을 2변수 함수의 곡선은 그래프에 `0=g(x,y)`로 쓴다.** `g(x,y)=0`으로 쓰면 Desmos가 「g의 정의」로 읽어 CL이 그 줄을 지우고 곡선이 그려지지 않는다. (1회 관찰)
- 그래프 표현 레시피는 `graph-cl-recipes.md`.

## 8-1. 그래프·기하학으로 그린 뒤 그림판으로 바꾸기 (학생이 그림 위에 필기)
학생이 그림 위에 직접 세거나 표시해야 하는 장면(합 표, 격자, 작도 등)에 쓴다. 그래프로 정확히 그린 그림을 배경으로 두고, 학생은 그림판 도구로 그 위에 쓴다.
1. 그래프(또는 기하학) 구성요소로 그림·작도를 완성한다.
2. 구성요소 「⋯」(Open More Component Options) → 「다음으로 변환:」 → 「그림판」. (그래프의 변환 목록: 「그래핑 계산기」(비활성), 「그림판」)
3. 바뀐 그림판의 「⋯」 → 「설정」에서 학생 도구를 고른다: 연필, 선, 텍스트, 수식, Eraser, White background.
4. 그림판의 「배경」 메뉴에는 빈 배경 / 편집 가능한 그래프 / 기하학 / 이미지 업로드가 있다. 변환하면 배경이 「편집 가능한 그래프」가 되고, 「그래프 편집」 링크로 배경 그림을 계속 고칠 수 있다.
5. 되돌리기: 그림판 「⋯」 → 「다음으로 변환:」 → 「그래프」.
- 저장값: 구성요소 키가 `sketch`가 되고, `background: {type: "graph"}`, `calculatorState`(식 그대로), `swappedComponentData`(원래 `input/graph` 보관), `enabledTools`, `aspectRatio`가 생긴다.
- 동작: 그림판의 배경 그래프·기하학은 원래 구성요소와 같은 방식으로 동작한다. 점 끌기와 CL 연결도 그래핑 계산기와 같고, 「그래프」로 되돌리면 원래 그래프가 그대로 돌아온다. 기하학 구성요소도 같은 「다음으로 변환 → 그림판」 경로를 쓴다. (1회 관찰)
- **그림판의 배경 그래프·기하학(왼쪽 그림을 오른쪽에 복제하는 화면)은 로딩 직후에는 비어 있고, 학생이 원래 그래프의 점을 실제 마우스로 끌어야 나타난다.** 로딩 직후나 API·키보드로 상태를 바꾼 뒤만 보고 「배경이 안 그려진다」고 판정하지 않는다. 판정은 실제로 끈 뒤의 스크린샷으로 한다. (확인됨)
- **학생이 풀이를 쓰는 풀이 공간**은 그림판을 추가하고 「배경」→ 이미지 업로드로 `assets/memo-pads/`의 리걸패드(G0에서 고른 종이, 두 열 화면 `_1x1.png`, 전체 폭 M.E.M.O `_16x9.png`)를 넣는다. 사용자 지침이 있으면 그것을 따른다. 같은 활동에 이미 풀이 공간이 있으면 그 저장값(배경 이미지, 비율, 도구)을 읽어 똑같이 맞춘다. 빈 그림판을 넣지 않는다.
- 그림 배경 그림판 대신 그래프 구성요소로 도형만 보여 줄 수도 있다. 학생이 도형 위에 직접 표시해야 할 때만 그림판으로 바꾼다.

## 9. CL 넣기
- 구성요소 「스크립트 열기」 → `.script-modal-editor .CodeMirror`의 `CodeMirror.setValue(코드)` → 오류 표시 `.cm-cl-error`가 없는지 확인 → 「완료」. CL 문법은 `../knowledge/`의 `cl-sinks.md`·`cl-judgments.md`·`cl-pitfalls.md`로 확인한다.
- 「완료」가 스냅샷에 잡히지 않으면 화면에 보이는 「완료」 요소의 좌표를 눌러 닫는다. 닫힌 뒤 창이 남아 있지 않은지 확인한다.
- 구성요소별 sink 목록은 스크립트 창 오른쪽 「N sinks / N sources」 문서에 나온다(예: 수식 답변에 `suffix`가 있음). 판정 패턴은 `graph-cl-recipes.md`.

## 9-1. 스크립트 창을 열 때의 주의
- 화면 스크립트(왼쪽 위 `</>`)는 **지금 선택된 화면**의 것이 열린다. 화면 이동이 실패하면 다른 화면 스크립트를 덮어쓴다. 열기 전에 `location.hash`에 대상 화면 id가 있는지 확인하고, 창을 연 뒤 `CodeMirror.getValue()`가 기대한 원래 코드인지 확인한 다음에 바꾼다.
- 바꾼 뒤에는 대상 화면뿐 아니라 **모든 화면의 화면 스크립트**를 저장값으로 다시 비교한다. CL은 다른 화면 구성요소도 읽을 수 있어서, 잘못 들어간 스크립트도 오류 없이 동작한다.
- 「완료」는 `button`이 아니라 `span`이다. DOM `click()`이 안 먹을 때가 있어 좌표 마우스 클릭으로 누른다. `setValue` 뒤 키 입력을 한 번(공백 입력 후 지우기) 해야 변경이 저장되었다.

## 9-2. 화면을 JSON으로 붙이기 (확인됨)
- **JSON 붙이기는 UI로 만들 수 있는 구성을 빠르게 옮기는 수단이다.** UI에 없는 종류나 설정(칸 안의 그래핑 계산기 등)을 만드는 데 쓰지 않는다.
- 화면 복사는 클립보드에 `vnd.desmos.ab.screen` 형식(`{version:3, stepConfig:{version:1, steps:[화면]}}`)으로 들어간다. 합성 paste 이벤트는 무시되므로, `DataTransfer.prototype.setData`를 가로채 실제 Meta+C 때 내용을 바꿔 넣고 Meta+V로 붙인다. Meta+C는 포커스가 `body`일 때만 화면 복사가 된다.
- 붙는 자리는 **선택된 화면 다음**이다. 썸네일을 눌러도 선택이 안 바뀔 때가 있으니(화면이 엉뚱한 자리에 붙을 수 있다) `location.hash`로 선택을 확인한 뒤 붙인다.
- **JSON으로 화면을 만들 때 메모 글의 모양(수식은 반드시 수식 노드로):** 메모 구성요소(`exhibit/text`)의 `doc`은 문자열로 된 JSON이다. 문단 안에서 수식은 `type: "mq"` 노드이고, 그 안에 LaTeX 한 덩어리를 text로 넣는다. 일반 글자는 `type: "text"` 노드다. (확인됨)
  ```
  {"type":"doc","content":[{"type":"paragraph","attrs":{"alignment":"left","indent":0},"content":[
    {"type":"mq","content":[{"type":"text","text":"y=ax^{2}"}]},
    {"type":"text","text":"의 그래프가 아래로 볼록하게 하는 "},
    {"type":"mq","content":[{"type":"text","text":"a"}]},
    {"type":"text","text":"의 값을 고르시오."}]}]}
  ```
  큰 글자는 문단 대신 `{"type":"heading","attrs":{"level":2,"alignment":"left","fontWeight":null},"content":[…]}`, 굵게와 글자색은 text 노드의 `marks`(`{"type":"strong"}`, `{"type":"color","attrs":{"hex":"…"}}`)로 넣는다. (1회 관찰) 수식을 일반 text 노드에 `y=ax^2`처럼 쓰면 수식으로 그려지지 않는다. 객관식 선택지는 문자열 안에 백틱(`` `a=1` ``)으로 감싼다.
- **제출칸(자유 답변·수식 답변)은 화면 JSON 붙여넣기로 만들지 않는다.** 저장값이 같아도 JSON으로 붙인 칸은 제출 버튼이 비활성으로 남을 수 있다(원인 미확인). 「자유 답변」·「수식 답변」 추가 버튼(UI)이나 「구성 요소 복사」로 만든 칸은 제출이 켜진다. 제출칸이 있는 화면은 구성요소를 UI로 추가한다. (1회 관찰)
- 화면을 통째로 바꿔 끼우면 화면 id가 바뀐다. 바꾸기 직전에 저장값을 다시 읽어, 그 사이 사용자가 고친 것이 있으면 그것을 바탕으로 만든다(절대 원칙).
- 동시에 두 탭에서 같은 액티비티를 편집하면 한쪽은 저장이 꺼진다(「다른 창에서 편집 중」 경고). 사용자가 편집 중이면 새로고침으로 편집권을 빼앗지 말고 멈춘다.

## 10. 교사 팁·미리보기
- **교사 팁을 화면 교체 없이 고치기**: 팁 편집기는 `dispatch({type:'teacher-tip-input', path:[화면id], pmNode})`로 저장한다. 팁 편집기에서 한 글자 입력해 얻은 `pmNode.type.schema.nodeFromJSON(doc)`으로 새 문서를 만들어 보낸다. **팁 편집 창이 열려 있으면 닫힐 때 옛 내용으로 덮어쓴다.** 창을 닫은 뒤 보내고, 새로고침 뒤 저장값으로 확인한다. (확인됨)
- 「교사용 팁 편집」 → Rich text editor에 입력 → **「완료」를 눌러야 저장된다.**
- 미리보기: 「미리보기」 → `.modal-container`, 이동 `.nav-stepper-next/previous`, 위치 `[role=navigation]`(「현재 화면은 N의 M」). 미리보기에서 시험 입력한 값은 활동에 저장되지 않는다. 요소 스크린샷은 깨지므로 페이지 스크린샷을 쓴다.
- **발행은 저장과 별개다.** 편집은 자동 저장되지만 학생이 보는 것은 발행본이다. 발행 전에는 학생에게 예전 상태가 보인다.
- **미리보기를 열기 전에 편집기 포커스를 풀어라(`document.activeElement.blur()`).** 풀지 않으면 미리보기에서 친 글자가 편집기에서 마지막으로 누른 칸(예: 선택지 글)으로 새어 들어가 원본이 망가진다. 미리보기 시험 뒤에는 저장값을 다시 읽어 엉뚱한 변경이 없는지 확인한다. (1회 관찰)
- 미리보기의 표·수식 칸은 칸 안 `.dcg-mq-edit` 요소 중앙을 마우스로 눌러야 입력이 들어간다. `textarea`에 포커스를 주거나 스냅샷 ref를 누르는 방식은 입력이 들어가지 않는다. 칸 안의 분수를 지울 때는 Ctrl+A 후 Backspace가 확실하다. 칸이 커지면 다른 칸 위치가 바뀌므로 좌표를 매번 다시 잡는다.
- 미리보기 창 바깥을 누르면 미리보기가 닫힌다. 미리보기 안 그래프의 점은 `Desmos.getCalcByElement` + `mathToPixels`로 좌표를 얻거나 스크린샷 좌표로 끌 수 있다.
- 학생이 답을 입력하는 중에도 CL은 바로 반응한다(제출 전에 다음 단계가 열릴 수 있음). 제출 뒤에만 열려면 별도 설계가 필요하다(미확인).

## 11. 브라우저 AI로 작업할 때의 환경 주의
- 화면 PNG는 HTML로 그리고 로컬 HTTP 서버(localhost)에 띄워 브라우저 탭 스크린샷으로 렌더한다. `file://` 주소는 차단될 수 있다. 2배 해상도로 찍는다. (확인됨)
- 파일 업로드 입력은 AI 도구가 허용한 폴더 밖의 파일을 거부할 수 있다. 허용된 임시 폴더로 복사해 내용이 같은지 확인한 뒤 올린다. (확인됨)
- 같은 이름의 변수를 다시 선언할 수 없는 실행 환경이 있다. 호출마다 새 이름을 쓴다.
- 브라우저 창 폭이 바뀌면 학생 미리보기가 한 줄 배치(그래프가 넓게)로 보여, 그래프 안 상자와 글자의 비율이 달라진다. 크기 판단은 두 줄 배치에서 한다.
- 작업 전에 활동 페이지에서 발행 상태(「마지막 발행 일시」, 「초안 수정」)를 확인해 두고, 보고에 적는다.
- **카드 정렬을 자동 조작으로 검증할 때** (사람이 손으로 할 때는 필요 없다, 1회 관찰)
  1. 카드 정렬 영역의 아래쪽 카드나 다른 묶음에 가린 카드를 먼저 영역 위쪽의 빈 공간으로 옮긴다. 위쪽 공간에서 짝을 한 쌍씩 합친다.
  2. 카드가 겹치면 같은 자리를 다시 끌지 않는다. 가려지지 않은 자리를 확인하고 카드를 떼어 위쪽에 다시 놓은 뒤 끈다.
  3. 잘못 묶으면 그 카드를 위쪽 빈 공간으로 떼어 내고 올바른 짝과 다시 합친다.
  4. 끌기는 실제 마우스 누름 → 잠깐 대기 → 천천히 이동 → 겹침 반응 대기 → 놓기 순서로 한다(시간은 환경마다 다르다).
  5. 모든 쌍을 묶어 완료 안내가 바뀌는지 학생 미리보기에서 확인하고, 시험한 상태가 원본에 남지 않았는지 대조한다.
  6. 가림·겹침으로 조작이 안 되면 위치나 배율을 바꿔 다시 시도한 뒤 보고한다. 조작 방법의 문제를 작업이 막힌 이유처럼 보고하지 않는다.
- 자동 조작 도구에서는 학생 미리보기의 수식 입력 칸이 바로 눌리지 않는다. 실제 입력창 크기가 0이라서다. 칸의 바깥 영역(`.dcg-mq-editable-field`)을 눌러 연다. (1회 관찰)
- 메뉴 버튼이 편집 영역 아래에 가려져 눌리지 않으면 먼저 화면 가운데로 굴려(`scrollIntoView({block:'center'})`) 보이게 한 뒤 누른다. (1회 관찰)

## 12. 학생 미리보기와 화면 만들기에서 알아 둘 규칙
- **학생 미리보기 시험은 실제 입력으로 한다.** 칸을 클릭한 뒤 타이핑하고, 점은 실제로 끈다. 값 주입, `fill`, `insertText`, 붙여넣기 이벤트는 화면 글자만 바뀌고 제출이나 CL 반응이 켜지지 않을 수 있다. (1회 관찰)
- **미리보기를 닫았다 다시 열면 입력 상태가 초기화된다.** 「이전/다음」으로 화면을 오가는 것은 상태가 유지된다. (확인됨)
- **그래프를 화면 JSON으로 붙일 때는 「표 식」 열(표와 연결된 식)을 포함한 식 목록 전체를 넣는다.** 이 데이터가 빠진 채 붙이면 편집기와 미리보기가 흰 화면으로 멈출 수 있다. (1회 관찰)
- **이미지를 data URL로 직접 넣으면 서버 저장 오류가 난다.** 정상 업로드 URL을 쓴다. (1회 관찰)
- **Polypad의 `polypadState`는 문자열이 아니라 객체다.** 현재 UI 기본값과 같은 형식으로 넣는다. 문자열로 넣으면 안 된다. (1회 관찰)
- **연결 이름만 보고 화면의 기능을 짐작하지 않는다.** 같은 이름의 연결도 실제 기능이 다를 수 있다(예: 「정답·해설 공개」로 보이는 연결이 실제로는 입력칸 공개). 자신이 만든 화면을 본보기로 삼을 때는 그 화면의 CL 연결 내용을 읽어 실제 기능을 확인한다.
