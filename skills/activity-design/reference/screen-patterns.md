# 화면 구성 패턴: 구성요소 조합과 CL 연결

직접 만든 액티비티(공식 활동 아님)의 저장값을 화면별로 분석한 화면 패턴이다. 권장하는 구성은 **권장 구성**으로 따로 표시했다. (확인됨)

## 0. 읽는 법
- 「배치」는 왼쪽 열 → 오른쪽 열 순서다. `[이름]`은 구성요소 별칭(alias)이다.
- 「연결」은 `받는 쪽 sink ← 읽는 값` 이다. 단계 열기는 대부분 `hidden:` sink 하나로 한다.

## 1. 단계 열기(hidden 사슬)의 기본형
| 앞 단계 | 뒤 구성요소의 CL | 쓰는 장면 |
|---|---|---|
| 표 여러 칸이 모두 맞음 | `hidden: not(tbl.script.allOK = 1)` (표 CL에서 `allOK = when ok1 and ok2 1 otherwise 0`) | 표를 풀어야 다음 단계가 열리는 화면 |
| 표의 특정 칸만 맞음 | `hidden: not(tbl.script.ok1 and tbl.script.ok2)` (표 CL의 변수를 바로 읽음) | 일부 칸만 맞아도 넘어가는 화면(권장 구성) |
| 표를 다 채움(정답 무관) | `allfill = not(isBlank(this.cellContent(1,1)) or …)` → `hidden: not(tbl.script.allfill)` | 채우는 활동 자체가 목적인 화면(권장 구성) |
| 객관식 정답 | `hidden: not(mc.matchesKey)` (편집기에서 정답 표시 필요) | 고른 답이 맞아야 넘어가는 화면 |
| 객관식 특정 보기 선택 | `hidden: not(mc.isSelected(1))` | 특정 보기를 고르면 열리는 화면 |
| 글 입력 제출 | `hidden: not(txt.submitted)` | 서술을 제출해야 넘어가는 화면(권장 구성) |
| 글 입력을 정해진 문장과 똑같이 쓰고 제출 | 글 칸 CL `writeOK = this.content = "정해진 문장" and this.submitted` → `hidden: not(write.script.writeOK)` | 고른 문장을 그대로 옮겨 쓰게 하는 화면(권장 구성) |
| 수식 답이 맞음 | 수식 CL `okN = when ok 1 otherwise 0` → `hidden: not(ans.script.okN = 1)` | 단계별 식 입력 화면 |
| 그림판에 충분히 표시함 | `hidden: … or pad.sketch.strokeCount < 9` | 그림 위에 표시해야 넘어가는 화면(권장 구성) |
| 그래프 안 상태 | 그래프 식 결과를 `graph.number("c")`로 읽음 | 그래프 조작 결과로 판정하는 화면 |
| 버튼 누름 | `btn.pressCount` | 버튼으로 단계를 여는 화면 |

- 같은 조건을 쓰는 메모(발문)와 입력칸은 **둘 다 같은 hidden**을 단다. 발문만 보이고 칸이 안 보이는 일이 없게 한다.
- 조건이 길면 받는 쪽이 아니라 **보내는 쪽 CL에서 변수로 만들어** 읽게 한다(`allOK`, `okN`, `writeOK`, `allfill`). 이름 붙은 변수는 `구성요소.script.변수`로 읽는다.

## 2. 피드백 sink
| 구성요소 | sink |
|---|---|
| 표 | `cellSuffix(r,c)` ✅/❌, `correct` |
| 수식 답변 | `suffix`, `errorMessage`(틀린 이유 안내), `placeholderLatex`, `correct` |
| 수식 답변(제출형) | `showSubmitButton`, `submitLabel: "확인"`, `resetLabel`, `disableEvaluation: true`, `correct: this.submitted and ok`, `suffix: when not(this.submitted) ""…` |
| 화면 | `subtitle`(단계별 안내·칭찬, `\textcolor{}` 색), `coverText`·`coverButtonLabel`(축하 팝업) |
| 객관식 | `prompt`(앞 메모에 발문이 있으면 `""`) |
| 글 입력 | `initialText`(쓸 틀을 미리 줌: 「⑴ 첫 번째 답:」) |
| 그림판 | `hidden`, `disableSketch`, `readOnly` |
| 그래프 | `number("변수")`로 다른 구성요소 값을 넣음, `correct`(대시보드), `saveOnChange` |

## 3. 구성요소 조합 유형
1. **상황 그림 + 표 → 객관식 → 글 입력**: 왼쪽 그림·상황·표, 오른쪽에 표를 맞히면 객관식 두 개, 둘 다 맞히면 글 입력.
2. **움직이는 그래프 + 객관식으로 조작**: 객관식 선택을 `number("v")`로 그래프에 보내 장면을 재생, 끝까지 보면(`number("w")=3`) 정리 문항이 열림, 다시보기 버튼은 `disabled`로 잠금.
3. **카드 정렬 + 화면 축하**: 카드 정렬은 CL sink가 없어서 화면 CL에서 `sortProb.matchesKey`로 `subtitle`·`coverText`.
4. **체크박스 → 그래프 → 문장 만들기**: 체크박스 `isSelected(1~6)`를 그래프 `number("k_1"…)`로 보내고, 메모 CL에서 고른 항목을 이어 붙여 문장(`show = "선택한 항목 : …"`)을 만든다.
5. **그래프 조작 판정 → 표 → 부등식**: 화면 `subtitle`이 상황별 안내(정답, 너무 넓음, 빠진 점).
6. **표 → 합 → 식, 수직선이 단계마다 바뀜**: 수식 답의 `okN`을 그래프 `number("g_v")`로 보내 그림이 단계적으로 드러남.
7. **방법 비교 표 → 객관식 → 까닭 쓰기**.
8. **필기량으로 힌트 단계**: 그림판 `strokeCount`를 그래프로 보내 `H_hint` 단계를 계산, 화면 `subtitle`이 힌트, 버튼 두 개로 이전 풀이/현재 풀이 전환.
9. **권장 구성: 서술 → 제출 → 표 → 답**: 반대 경우를 글로 쓰게 하고(`submitted`), 표는 정답 표시 없이 채우면(`allfill`) 마지막 발문과 답 칸.
10. **권장 구성: 고르기 → 같은 문장 쓰기 → 그림판 표시 → 표 → 답**:
   - 왼쪽: `① 상황 + 첫 발문`(메모 하나) → 객관식(정답 표시 없음, 무작위, 목록) → 글 칸(`writeOK`: 고른 문장을 그대로 써서 제출).
   - 오른쪽: `③ 최종 발문`(표를 맞히면) + 답 칸 → `② 안내`(CL `content`에 `oppMCD.choiceContent(1)`를 넣어 「위 '고른 문장'에 해당하는 경우를 모두 표시한 후 나타나는 표를 채우시오.」) → 표(`writeOK`이고 그림판 9획 이상) → 격자 그림판(`writeOK`).
   - 단계 번호 ①②③을 발문 앞에 붙여 순서를 보여 준다. 나중에 열리는 ③을 오른쪽 맨 위에 둔다.
11. **권장 구성: 그림 선택지**: 체크박스 선택지를 글 대신 그림 4장(격자 배치, 무작위)으로.
12. **M.E.M.O 화면**: 화면 제목 「M.E.M.O」, G0에서 고른 리걸패드(`assets/memo-pads/`의 `_16x9.png`)를 배경으로 한 전체 폭 그림판 하나. **0단계 구성표의 절이 끝날 때마다 기본으로 넣는다**(구성표와 분포표에 미리 적는다).
13. **OX 문제 화면**: 메모(문장) + 객관식(O/X) 반복.
14. **돌아보기 화면**: 왼쪽 메모 + 이해도 그래프, 오른쪽 메모 + 글 입력.
15. **교과서 문제 화면**: 한 문제(⑴⑵ 같은 소문항 포함)를 한 화면에 둔다. 왼쪽 열 = 문제 글(교과서 원문, 판단 자료가 필요하면 그 아래 그래프·그림), 오른쪽 열 = 답 칸(수식 답변·표 등, ✅/❌) + 풀이 공간(리걸패드 `_1x1.png` 그림판). 판단 자료가 없으면 구성요소 3개 안팎이 되어 `illustration.md`의 그림 추천 조건에 맞는다. 여러 문제를 한 화면에 묶지 않는다.

## 4. 설계 방향 요약
- 구성요소 수를 줄이고(상황+첫 발문 합치기, ❌ 메모·확인용 객관식 삭제), 학생 활동(쓰기, 표시하기)을 늘린다.
- 도구는 버튼 대신 단계 조건으로 연다.
- 다음 안내에 학생이 고른 답을 인용한다(`choiceContent`).
- 주석은 그 줄이 하는 일을 한국어로 짧게(`#위의 writeOK라는 변수가 만족되지 않으면 숨김`).
