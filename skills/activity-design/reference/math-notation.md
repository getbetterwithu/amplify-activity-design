# 수식 쓰기 규칙 (메모·수식 답변·객관식·카드·CL)

Amplify Classroom의 수식은 표준 LaTeX 전체가 아니라 **등록된 명령만** 그린다. 지원하지 않는 명령은 글자로 남지 않고 **칸이 통째로 비워진다.** 그 줄의 수식 전체가 사라지므로 아래 허용 목록과 대체표를 따른다.

- 근거: 편집기의 계산기·메모·수식 답변·CL 네 경로에서 같은 수식을 시험했고 결과가 같았다. (확인됨)
- 범위: 중·고등학교 수학 교사가 쓰는 수식 중심이다. 전수 검사가 아니다. 이 문서에 없는 명령은 「확인하지 않음」이다.
- 확인하지 못한 것: 학생 계정 화면(편집기 미리보기까지만 확인), 다른 브라우저·모바일, 유니코드 기호 전체.

## 1. 화면 글의 기본 원칙
- **화면 글의 모든 수식·문자·숫자·분수는 수식 노드로 넣는다.** `y=ax^2`, `x^2=6^2+8^2`, `\sin A`처럼 수식 꼴을 일반 글로 두면 수식으로 그려지지 않는다. 화면을 JSON으로 만들어 붙일 때의 노드 모양은 `editor-ops.md` 9-2절. 끝나면 저장값 점검(`lint.md`)으로 수식 밖에 수식 꼴이 남지 않았는지 확인한다. 걸린 것이 있으면 완료가 아니다.
- **숫자는 웬만하면 모두 백틱 수식**으로 쓴다(`` `1` ``의 눈, `` `260` ``쪽). 일반 글자로 두면 수식 숫자와 모양이 달라 어색해진다.
- 분수는 빗금(1/2)이 아니라 **세로 분수** `\frac{1}{2}`로 쓴다.
- 숫자 나열은 한 수식 안에 넣고 쉼표 뒤를 `\ `로 띄운다(`1,\ 2,\ 3,\ 4,\ 5,\ 6`). 쉼표를 수식 밖에 두면 수식 여백 때문에 「1 , 2」처럼 틈이 생긴다.
- **수식 안에 한글을 넣지 않는다.** 수식 노드와 객관식·카드·정렬 항목의 백틱 안은 수식 글꼴이라 한글이 섞이면 글자 모양이 달라진다. 수식과 글이 함께 있으면 **수식 → 일반 글 → 수식** 순서로 백틱을 열고 닫는다. 예: `` `x-2=0` 또는 `x-3=0` `` (`` `x-2=0\ 또는\ x-3=0` ``은 쓰지 않는다). `\text{}`도 그려지지 않는다. (확인됨)

## 2. 점 이름과 약자
- **점 이름(꼭짓점, 점)은 `\mathrm{}`으로 감싼다:** `\mathrm{ABC}`, `\angle\mathrm{ABD}`, `\overline{\mathrm{BD}}`, `\triangle\mathrm{ABC}`. 쓰지 않으면 기울어진 글자가 되어 교과서 표기와 다르다. 변·변수 문자(`a`, `b`, `x`, `y`)는 감싸지 않는다.
- 굵게는 선택 사항이다. 원문의 점 이름이 실제로 굵게 보일 때만 `\mathbf{\mathrm{ABC}}`처럼 겹쳐 쓴다. 겹쳐 쓴 모양은 학생 미리보기에서 확인한다. (미확인)
- 합동·닮음 조건의 약자(SSS, SAS, ASA, AA 등)도 `\mathrm{SSS}`처럼 쓴다. 약자 뒤의 한글은 수식 밖: `` `\mathrm{SSS}` 닮음 ``.
- 기존 화면을 고칠 때도 같은 화면의 점 이름을 **모두** 같은 방식으로 맞춘다. 점검 스크립트(`lint.md`)가 안내로 알려 준다. 한 글자 점 이름(「점 P」의 P)도 수식 노드에 `\mathrm{P}`로 넣는다.

## 3. 입력 경로별 작성법
| 경로 | 방법 |
|---|---|
| 메모, 수식 답변(편집기에서 직접) | **붙여넣기로 넣는다.** 키보드로 `\frac`을 한 글자씩 치면 명령이 되지 않고 백슬래시 글자로 남는다. 교사에게 결과를 줄 때도 복사해서 붙여넣게 안내한다. |
| CL `content` 문자열 | 백슬래시를 **두 번** 쓴다. 예: `` content: "분수 `\\frac{1}{2}`" `` 한 번만 쓰면 `\n`으로 시작하는 명령이 줄바꿈으로 읽혀 깨진다. |
| 계산기 수식 칸 | 같은 명령이 같게 그려진다. |

## 4. 공백
- 공백은 스페이스바가 아니라 `\ `(백슬래시 + 공백)이다.
- 복사해 쓴 기호(∽ ≡ ⫽ ∴ ∵ ⇒) 앞뒤에는 반드시 넣는다. 없으면 글자가 달라붙는다.
- 등호 `=`와 비례식 콜론 `:` 앞뒤에는 넣으면 보기 좋다.
- `+ − × ÷` 앞뒤에는 넣지 않는다. 자동으로 벌어진다.

## 5. 쓸 수 있는 명령 (시험에서 그려진 것)
- **기하:** `\overline{\mathrm{AB}}` 선분 · `\underline{\mathrm{CD}}` · `\overleftrightarrow{\mathrm{PQ}}` 직선 · `\overarc{\mathrm{AB}}` 호 · `\overrightarrow{}` `\overleftarrow{}` 반직선 · `\triangle\mathrm{ABC}` · `\angle\mathrm{A}` · `\measuredangle` · `40\degree` 도 · `\perp` · `\parallelogram` · `\bigcirc` · `\square`
- **식의 구조:** `\frac{1}{2}` · `\sqrt{2}` · `\sqrt[3]{8}` · `x^2` `x^{10}` · `a_1` `a_{12}` · `\binom{n}{k}` · `\left(` `\right)` · `\sum_{k=1}^{n}k` · `\prod_{i=1}^{n}i` · `\int_0^1 x`
- **연산·관계:** `\neq` `\leq` `\geq` · `\times` `\div` `\cdot` · `\pm` `\mp` · `\infty` · `\to` · `\approx` · `2:3`
- **서체·색:** `\mathbf{}` 굵게 · `\textcolor{red}{}` 또는 `\textcolor{#2f6bd8}{}` (실제 색이 적용됨)
- **함수:** `\sin` `\cos` `\tan` `\ln` `\log` `\max` `\min` `\gcd` `\exp` `\det` `\arg` 등은 곧은 글씨로 그려진다.
- **그리스 문자:** `\alpha` `\gamma` `\delta` `\lambda` `\mu` `\pi` `\sigma` `\phi` `\omega` `\Delta` `\Sigma` `\Omega` 등 대부분.
- **복사해서 쓰는 유니코드 기호:** `∽`(닮음) `≡`(합동) `⫽`(평행) `∴`(따라서) `≒`(근삿값) `∝`(비례) `⇔`(동치)는 계산기·메모에서 그려졌다. `∵`(왜냐하면) `⇒`(그러면)는 계산기 칸에서만 확인했다.
- `\dfrac`와 `\cfrac`는 그려지지만 `\frac`과 같으므로 `\frac`만 쓴다.

## 6. 각도 기호
- **`^\circ`는 쓰지 않는다.** 수식 전체가 빈칸이 된다. (확인됨)
- 대신 쓸 수 있는 방법은 둘이다. 둘 다 그려진다.
  1. 수식 안에 `\degree`: `` `40\degree` ``, `` `\angle\mathrm{A}=90\degree` `` (확인됨)
  2. 수식 뒤에 일반 글자 °: `` `\angle\mathrm{A}=90` ``° (1회 관찰)
- **한 활동 안에서는 한 방식으로 통일한다.** 사용자 지침에 정한 방식이 있으면 그것을 따르고, 없으면 1번(`\degree`)을 쓴다. 그래프 라벨처럼 수식 노드가 아닌 곳에서는 일반 글자 °를 쓴다.

## 7. 대체표 (쓰면 칸이 비는 것 → 대신 쓸 것)
| 의도 | 쓰지 않음 | 대신 |
|---|---|---|
| 따라서 | `\therefore` | `∴` |
| 왜냐하면 | `\because` | `∵` |
| 합동 | `\equiv` | `≡` |
| 그러면 | `\Rightarrow` `\implies` | `⇒` |
| 동치 | `\Leftrightarrow` | `⇔` |
| 도 | `40^\circ` | `40\degree` (6절) |
| 세제곱근 | `\cbrt{8}` | `\sqrt[3]{8}` |
| 분수 | `1\over 2` | `\frac{1}{2}` |
| 조합 | `n\choose k` | `\binom{n}{k}` |
| 평행 | `\|` `\Vert` `\vert\vert` `\sslash` `\mathbin{//}` `\text{//}` | `⫽` |
| 간격 | `\quad` `\;` `\:` `\!` | `\ ` (`\!`는 그냥 뺀다) |
| 서식 래퍼 | `\mathbin{}` `\mathrel{}` | 안의 내용만 쓴다 |
| 말줄임 | `\ldots` `\cdots` | `…`를 백틱 밖에 |
| 글자 | `\text{AB}` | 한글·설명은 백틱 밖, 꼭짓점은 `\mathrm{AB}` |
| 그 밖 | `\underbrace` `\overbrace` `\mathbb` `\propto` `\bot` `\leftarrow` `\backsim` | 쓰지 않음 (`∝`은 유니코드로 가능) |

평행·간격·서식 래퍼 줄은 같은 계열의 수식 엔진에서 시험한 결과이고, Amplify 화면에서 하나씩 다시 시험하지는 않았다. (1회 관찰)

## 8. 그려지지만 모양이 다른 것
| 입력 | 실제 모양 | 권장 |
|---|---|---|
| `\sim` | 물결 `~` | 닮음은 `∽` |
| `\parallel` | 곧은 평행 `∥` | 평행은 `⫽` |
| `\cong` | `≅` | 합동은 보통 `≡` |
| `\lim` `\lim_{x\to 0}` | 이탤릭 낱글자 l·i·m | 곧은 글씨가 필요하면 쓰지 않음 |
| `\deg` `\dim` `\inf` `\sup` `\Pr`, `\operatorname{}` 등 | 이탤릭 낱글자 | 곧은 글씨가 필요하면 쓰지 않음 |

`\vec` `\hat` `\dot` `\tilde`는 그림은 정상이고, 화면 낭독에만 `undefined`가 붙는다.

## 9. 교과서 문장·사진을 옮길 때
1. 원문에 있는 내용만 옮긴다. 지어내거나 빠뜨리지 않는다.
2. 원문의 줄바꿈과 들여쓰기를 살린다. 한 줄 안에서 수식만 백틱으로 감싸고 한글 문장은 백틱 밖에 둔다.
3. 백틱 밖에 두는 것: 말줄임표, 번호표(①), `(AA 닮음)` 같은 한글 괄호 설명.
4. 교과서와 모양이 다른 기호는 명령 대신 유니코드를 수식 안에 넣고 앞뒤에 `\ `를 둔다: 닮음 `∽`, 합동 `≡`, 평행 `⫽`, 따라서 `∴`, 왜냐하면 `∵`, 그러면 `⇒`, 동치 `⇔`, 근삿값 `≒`, 비례 `∝`.
5. 비례식은 콜론을 그대로 쓴다: `c\ :\ a\ =\ a\ :\ b`.
6. 교사에게 결과를 줄 때는 결과 전체를 하나의 `~~~` 코드 블록에 담는다(백틱이 들어 있어서 `~~~`를 쓴다). 대체표에 걸리는 명령을 고쳤으면 한 줄로 알린다. 목록에 없는 명령은 「확인되지 않았다」고 말하고 그려진다고 단정하지 않는다.

예: 교과서의 한 줄 「△ABC ∽ △DEF 이므로 ∠A = ∠D」
~~~
`\triangle\mathrm{ABC}\ ∽\ \triangle\mathrm{DEF}` 이므로 `\angle\mathrm{A}\ =\ \angle\mathrm{D}`
~~~
