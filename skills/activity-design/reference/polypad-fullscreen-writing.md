# 폴리패드 전체화면 필기용 프리셋

## 적용 범위
교사가 이미지와 문제 글을 고정해 두고 학생은 표시·풀이·답만 쓰는 **순수 필기 작업지**에 사용한다. **교사가 준 이미지가 크거나 글자·그림이 선명해야 하면 그림판 배경 대신 이 화면을 쓴다**(아래 「그림판 대신 쓰는 이유」). 타일 조작 탐구에는 이 프리셋을 강제하지 않는다. 필기 이외의 조작을 줄이려는 경우에 선택할 수 있는 프리셋이다. 특정 교사의 개인 기본값은 해당 사용자의 지침에서 정하고, 이 문서의 값을 모든 수업에 강제하지 않는다.

## 기본 구성
- Polypad 전체화면을 선택한다. 배경은 **고정 캔버스 16×9**(저장값 800×450), 격자는 없음으로 한다.
- **학생 도구는 펜·지우개·텍스트·색상만** 둔다. 학생이 풀이 글을 새 텍스트창에 입력할 수는 있지만 문제 원문은 바꿀 수 없게 한다.
- 자료 이미지는 이미지 타일, 문제 글은 **별도의 실제 텍스트창**으로 넣는다. 글을 이미지로 합치지 않는다. 이미지·문제 텍스트는 잠금, 문제 텍스트의 편집 가능은 끔이다.
- 여백도 같은 캔버스의 필기 공간이다. 별도 리걸패드·그림판으로 쪼개지 않는다.
- 작성 모드는 교사가 설정을 편집하는 모드다. 아래 학생 도구 옵션과 구분한다. 최종 인계 전에는 작성 모드를 끄고 학생 미리보기로 확인한다. 사용자가 편집 중이면 모드를 임의로 바꾸지 않는다.

## 선택형 설정
- 그리기 도구: **펜과 지우개**(limited).
- 액션바 고정: **커스텀**(custom).
- 배경 캔버스: **결정된/고정**(fixed), 치수 16×9.
- 배경 격자: 없음(none).
- 구성요소는 전체화면 폴리패드(isManipulative: false), 자동 크기 조정 끔(shouldAutoResize: false).

## 검증된 저장 옵션
다음은 설정 화면과 대조한 options이다. 없는 속성을 임의로 true/false로 추가하지 않는다. 화면에서 꺼져 있지만 저장값에 별도 키가 없는 항목도 위 목록으로 확인한다.

```json
{
  "settings": "other",
  "mergeTiles": false,
  "evalEquations": false,
  "canvasX": 800,
  "canvasY": 450,
  "grid": "none",
  "canvas": "fixed",
  "algebraXSize": 5.4,
  "algebraYSize": 4.7,
  "pinActions": "custom",
  "sketchMode": "limited",
  "initiallyClosedSidebar": true,
  "noPinchPan": true,
  "noAudio": true,
  "noConfetti": true,
  "sidebar": "hidden",
  "toolbar": "pen,eraser,text,color",
  "noDeleting": true,
  "noCopyPaste": true,
  "noRotating": true,
  "noMusic": true
}
```

- toolbar의 값은 정확히 `pen,eraser,text,color`다.
- `settings: "other"`는 편집기의 현재 설정 탭 표시다. 학생용 필기 기능으로 해석하지 않는다.
- `algebraXSize`, `algebraYSize`는 함께 저장된 값이며, 이 필기 프리셋의 도구나 작업지 치수를 뜻하지 않는다.
- 숨김·끔으로 저장되는 `no…` 키는 뜻이 반대이므로 주의한다. 예: noCopyPaste가 true이면 복사·붙여넣기 꺼짐이다.

## 텍스트창 안의 일부 글자만 크게·색칠하기
- 텍스트 타일 전체뿐 아니라 **선택한 구절만** 크기를 키우고 색을 바꿀 수 있다. 중요한 단어·구하는 사건을 강조할 때 텍스트창을 여러 개로 쪼개거나 글을 이미지로 만들 필요가 없다.
- 타일 전체 크기인 `fontSize`와 구절별 서식인 `html` 내부의 `<span style="font-size: 120%;">…</span>`을 구분한다. 전체 `fontSize`를 바꾸면 다른 본문까지 커지므로 부분 강조를 대신하지 않는다.
- 저장값 확인: 타일 전체 `fontSize: -2`를 유지한 채, 선택한 구절에만 `font-size: 120%`와 별도 `color`가 저장됐다. 형식 예시는 `<span style="font-size: 120%; color: rgb(15, 130, 242);">중요한 조건</span>`이다. 예시 문구는 새로 쓴 것이며 색은 고정 규칙이 아니다.
- 글을 고칠 때 기존 `span`의 크기·색 서식을 보존한다. 평문 전체 교체나 타일 전체 크기 변경으로 사용자의 부분 강조를 지우지 않는다.
- 설정 뒤에는 `html`에 부분 서식이 남고 전체 `fontSize`는 의도대로 유지됐는지 확인한다. 잠긴 문제 텍스트의 부분 서식도 유지된다.
- 부분 확대·색을 적용한 텍스트 타일은 저장값으로 확인했다. 선택 조작 자체를 자동화해 재현한 것은 아니다. (1회 관찰)

## 그림판 대신 쓰는 이유
- **큰 이미지를 그림판 배경으로 넣으면 이미지가 반드시 열화된다.** 그림판 배경은 업로드 뒤 크게 줄어든 크기로 저장되고(예: 원본 2400×1350이 659×371) 화면 폭에 맞게 다시 확대되어 흐려진다. 고해상도로 올려도 같다. 문제 글을 이미지에 합치면 글까지 흐려진다. (1회 관찰)
- 폴리패드의 이미지 타일은 원본에 가깝게 유지된다(예: 1660×615가 1600×592). 글은 별도 텍스트창으로 두어 흐려지지 않게 한다. 그래서 **이미지 위에 학생이 필기해야 하는 화면은 이미지가 크면 폴리패드 필기 화면을 기본으로** 한다. 그림판은 그래프·기하학을 변환한 배경(벡터)처럼 원래 선명한 것에 쓴다(`editor-ops.md` 8-1절). (1회 관찰)
- 원본 이미지 자체가 흐리면 어느 방법으로도 선명해지지 않는다. 이때는 다시 그리는 것을 제안한다(`illustration.md`).

## 변형: 이동을 허용하고 처음 화면을 고정하는 필기 화면
교사가 준 문제 이미지(글이 이미지 안에 들어 있는 자료)를 그대로 두고 그 위에 필기하게 할 때 쓰는 변형이다. 기본 프리셋과 다른 점만 적는다. (1회 관찰)
- 학생 도구에 **이동**을 더한다(펜·지우개·색상 + 이동). 텍스트 도구는 없다.
- 스케치 모드는 기본(`default`)이다. 스냅은 켜 둔다.
- **처음 화면을 고정**한다: 초기 뷰포트 타일을 두어 학생이 열자마자 문제 이미지가 보이는 위치와 크기가 되게 한다(예: 위치 10, 14 · 크기 740×386).
- 이미지는 잠금이고 쪽마다 한 장이다. 문제 글이 이미지 안에 있으면 **대체 텍스트(이미지 설명)를 반드시 채운다**(`lint.md`가 이미지 설명 누락을 찾는다).
- 설정 키는 기본 프리셋과 같은 `polypadState.options`이고, 이 변형에서만 `customInitialViewport`가 참이다. 학생에게 열리는 동작 목록(`actionbar`)이 저장값에 길게 들어 있는 경우가 있으나 학생에게 실제로 열리는지는 확인하지 못했다. (미확인)

## 검증 절차
1. 현재 사용자 저장값을 먼저 읽고 원문·배치·설정을 되돌리지 않는다.
2. 설정 화면의 체크 상태와 toolbar·options를 함께 비교한다. 특히 스냅 켬, 실행 취소 켬, 이동·수식·직선 끔을 확인한다.
3. 이미지 잠금, 문제 텍스트 잠금 및 editable:false를 확인한다. 학생이 새로 만든 풀이 텍스트와 혼동하지 않는다.
4. 미리보기에서 펜·지우개·텍스트·색상만 보이고, 필기·되돌리기 및 자료 잠금이 작동하는지 확인한다.
5. 파일 해상도와 실제 표시를 따로 검증한다. 폴리패드라고 무조건 무손실이라고 단정하지 않는다. 원본보다 약간 작게 저장될 수 있고(예: 1660×615가 1600×592), 그림판 합성 배경은 더 크게 축소될 수 있다(예: 659×371). 둘을 구분한다.
6. 교체·발행은 별도 승인 범위다. 설정 기록만 요청받았으면 액티비티에 쓰지 않는다.

플랫폼의 필수 제약이 아니라, 필기 전용 목적의 선택형 프리셋이다. 설정 화면·도구 모음 체크 상태와 저장값으로 확인했다. (1회 관찰)
