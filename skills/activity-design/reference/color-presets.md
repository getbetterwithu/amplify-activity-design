# 색 역할표와 색 프리셋

색을 즉흥으로 고르면 같은 색에 여러 뜻이 붙는다. 활동을 시작할 때 아래 프리셋 중 하나를 골라 역할표로 쓴다. 사용자 지침에 정해진 색이 있으면 그것이 우선한다.

## 처음 쓸 때 묻기 (스킬을 처음 호출했을 때, 작업 시작 전)
1. `color-presets-swatch.html`의 내용을 답변의 `visual` 블록으로 보여 준다. 세 프리셋의 색 견본 7개, 흰 바탕 메모 글자 예, 수직선 예를 나란히 보여 눈으로 고르게 한다.
2. 묻는다: 「어떤 것을 기본 색상으로 쓸까요?」 (① 기본형 / ② 차분형 / ③ 색약 배려형)
3. 답을 그 활동의 기본 색 규칙으로 기록하고 시작한다. 답을 받기 전에는 색을 정해야 하는 작업을 하지 않는다.
- 프리셋은 기본 역할 색이다. 문제 발문의 강조색을 화면마다 섞어 쓸지는 사용자 지침을 따른다(섞을 때는 옆 화면과 같은 화면에 이미 있는 색을 피하고, 뜻이 정해진 색을 빌려 쓰지 않는다).

## 역할 7개 (모든 프리셋 공통)
| 변수 | 역할 | 예 |
|---|---|---|
| `c_A` | 첫째 대상 | 사건 A, 첫째 상황 |
| `c_B` | 둘째 대상 | 둘째 상황, 나머지 집합 |
| `c_M` | 학생이 움직이는 것 | 끌 수 있는 점, 구간 핸들 |
| `c_R` | 결과 값·상자 | 확률 값 상자, 정리 결과 |
| `c_S` | 반드시·맞음 | 확률 1, 맞은 표시 |
| `c_N` | 절대로·틀림 | 확률 0, 틀린 표시 |
| `c_G` | 배경·나머지 | 격자선, 비활성, 보조 글 |

- 한 색에는 한 뜻만 둔다. 한 화면에서 뜻이 있는 색은 4가지 안팎으로 쓴다.
- 그래프 색과 메모 글자색은 짝이다. 연한 색은 흰 바탕의 작은 글씨에서 흐리므로 글자에는 같은 계열의 진한 색을 쓴다. 글자색은 모두 흰 바탕 대비 4.5 이상이다.

## 등록 방법
### 그래프 (색 변수)
1. 그래프 편집 창에서 폴더 「팔레트」를 만들고, 고른 프리셋의 7줄(`c_A=rgb(…)` …)을 넣는다. 각 줄에 색 견본이 붙는다.
2. 각 식의 색을 변수로 지정한다.
   - 편집 창에서: 식 왼쪽 아이콘을 길게 눌러 색 메뉴를 열고 팔레트 색을 고른다(사용자가 쓰는 방식).
   - API로: `getState()`로 받아 식에 `colorLatex: "c_{A}"`를 넣고 `setState`. `setExpression`의 `colorLatex`는 저장되지 않았다.
3. 저장 뒤 저장값에 `colorLatex`가 남았는지, 학생 미리보기에서 색이 나오는지 확인한다.
- 변수 한 줄만 바꾸면 그 색을 쓰는 식이 모두 바뀐다(저장값·미리보기 확인, 2026-11-08, 화면 복사본에서 시험 후 삭제).
- 여러 그래프에서 같은 팔레트를 쓰려면 팔레트 폴더를 그래프마다 넣는다(그래프끼리 변수를 공유하지 않는다).

### 메모 글자
- 메모는 그래프와 따로다. 붙여넣기 HTML의 `<strong><span style="color:#hex">…</span></strong>`로 글자색 열의 값을 쓴다(`editor-ops.md` 4절). 색 글자는 굵게 한다.
- 부제·덮개 글은 수식 안 `\textcolor{#hex}{…}`로 색을 낸다.
