# Desmos 액티비티 기능별 해결사전 (Cookbook)

> **목적**: Amplify Classroom 액티비티 설계 시 **"이런 화면/기능을 만들고 싶은데 어떤 함수를 써야 하는가?"**에 즉각 답하기 위한 목적 기반 역방향 레시피(Cookbook)입니다.
>
> 몰라서 쓰지 못했던 Desmos 내부의 강력한 함수들(`unique`, `sort(A, B)`, `argmax`, `distance`, `polygon`, `round(x, n)`, `random(seed)` 등)을 적재적소에 발굴하여 액티비티를 우아하고 짧은 코드로 완성할 수 있도록 돕습니다.
>
> **출처 및 기반**: [Desmos Calculator (psh7own5ep)](https://www.desmos.com/calculator/psh7own5ep) 전수 분석 데이터 및 Amplify 실측 검증
>
> 💡 **그래프 화면 제작 원칙**:
> 그래프를 쓰는 화면에서는 수식이나 함수만 나열한 정적 그래프를 두지 않는다. 학생이 조작할 수 있는 요소(드래그 가능한 점 `dragMode`, 표 입력, 행동 버튼 등)를 넣어 조작에 따라 그래프가 반응하고 피드백을 주게 한다.
> 그래프를 쓸지 말지는 이 문서가 아니라 화면 설계에서 정한다. 그래프는 움직여 봐야 보이는 연속 변화나 관계에 쓰고, 분류·순서·오개념 진단 같은 생각은 카드 정렬·정렬 리스트·객관식 같은 다른 구성요소가 더 맞을 수 있다. 조작에 반응하는 라벨·좌표·시작값이 정답을 먼저 보여 주지 않게 한다(아래 10번).
>
> ⚠️ **실측으로 밝혀진 런타임 10대 필수 제약**:
> 1. **리스트 내포식 `for` 문법**: 그냥 공백 ` for `로 쓰면 구문 에러가 난다. 반드시 `\operatorname{for}`로 감싸야 한다! (예: `[(k, f(k)) \operatorname{for} k = [1...5]]`)
> 2. **주사위 난수 정수화**: `uniformdist`는 연속 실수이므로 반드시 `\operatorname{floor}(\operatorname{random}(\operatorname{uniformdist}(1, 7)...))`로 감싸야 정수 주사위가 된다.
> 3. **CL 직접 산술 연산 금지**: CL 스크립트에서 `btn.pressCount + 1`처럼 직접 사칙연산을 쓰면 에러(`.cm-cl-error`)가 난다. 반드시 `numericValue("${...}+1")`로 감싼다.
> 4. **CL 변수 참조 따옴표 필수 및 인덱싱 분리**: `this.number("변수명")`처럼 반드시 큰따옴표로 감싸 전달하며, `graph.number("Y[i_{max}]")`처럼 수식·인덱싱은 직접 읽지 못하므로 그래프 안에 보조변수 `v_{max}=Y[i_{max}]`를 따로 정의해 읽어야 한다.
> 5. **다중 문자 변수명 암시적 곱셈 에러**: Desmos에서 `val_{exp}`, `isCorrect` 처럼 단어가 긴 영문 변수를 입력하면 엔진이 암시적 곱셈($v \cdot a \cdot l$)으로 파싱하여 **"x와 y에 대해서만 음함수를 그릴 수 있습니다"** 에러를 낸다. 변수명은 반드시 **한 글자 알파벳 + 밑줄 첨자** 형태(예: `v_{exp}`, `p_{ct}`, `i_{sCorrect}`)로 명명해야 한다!
> 6. **차트·통계 패널 표시 함수 6종 대입 금지**: `boxplot`, `histogram`, `dotplot`, `stats(L)`, `ttest(L)`, `ittest(X, L)`은 수치를 반환하지 않고 차트나 통계 패널을 렌더링하므로 변수에 대입(`S = stats(Y)`)하면 에러가 난다. 반드시 수식 한 줄에 단독 호출한다.
> 7. **차트 시각화 레이아웃(`vizProps`)**: `boxplot`, `dotplot` 등의 위치/높이는 수식이 아니라 계산기 내부 속성(`axisOffset`, `breadth`)으로 제어한다.
> 8. **t-검정 수치 반환(`tscore`) vs 패널 표시(`ttest`, `ittest`) 구별**: CL로 읽어올 단일 표본 t-통계량 숫자는 `tscore(Y, \mu)`를 쓰고, 수식창에 가설검정·신뢰구간 패널을 띄울 때는 1인자 `ttest(L)` 또는 2인자 `ittest(X, L)`을 단독 호출한다.
> 9. **백분율 `of` 연산자**: LaTeX에서 `25\% \operatorname{of} 100` 또는 `25\% \operatorname{of} H` 형태로 Desmos에서 그대로 수치 연산으로 지원된다.
> 10. **초기값 오답 세팅 및 삼각/로그 정의역 가드**: 드래그 점의 초기 좌표는 반드시 오답(`i_{sCorrect}=0`) 위치로 두며, $t=0, \pi/2$ 또는 로그 진수 $\le 0$에서 `undefined` 발생 시 CL에서 `when isDefined(graph.number("v_{ln}")) ... otherwise "정의되지 않음"`으로 방어한다.

## 1. 학생 데이터 집계, 중복 제거 및 필터링

### 1-1. 조별 제출 데이터에서 중복값 한 번에 제거하기
* **이전의 번거로운 방식**: 복잡한 조건부 루프나 외부 스크립트 처리
* **사용 함수**: `\operatorname{unique}(L)`
* **문법**:
  ```latex
  L_{clean} = \operatorname{unique}(L)
  # 또는 Dot Notation 체이닝
  L_{clean} = L.\operatorname{unique}()
  ```
* **CL 연계 예시**:
  ```text
  # 학생들의 응답 리스트 L을 그래프에 주입
  numberList("L"): table.columnNumericValues(1)
  ```
  그래프 내부에서 `unique(L)`을 적용하면 중복 응답이 제거된 고유 값 목록만 추출되어 그래프에 단 한 번씩만 점이나 막대로 표시됩니다.

### 1-2. 두 개 이상의 리스트 하나로 합치기
* **사용 함수**: `\operatorname{join}(L_1, L_2, ...)`
* **문법**:
  ```latex
  L_{total} = \operatorname{join}(L_1, L_2, [100, 200])
  ```
* **실전 팁**: 빈 리스트 방지용 안전 기본값 삽입에 필수적입니다.
  예: `join(L, 0)` $\rightarrow$ 만약 $L$이 비어있더라도 최소한 `0` 하나는 보장되므로 `max()`, `min()` 에러를 방지합니다.

### 1-3. 특정 조건을 만족하는 값만 골라내기 (조건 필터)
* **문법**: `L[조건]`
* **실전 예시**:
  ```latex
  L = [10, -5, 20, 0, 35, -2]
  L_{양수} = L[L > 0]             # 결과: [10, 20, 35]
  L_{구간} = L[L \ge 0][L \le 20]  # 다중 체이닝 필터: [10, 20, 0]
  ```
* **주의**: Desmos 필터 괄호 안에는 `and` 대신 `L[조건1][조건2]` 형태로 대괄호를 연속해서 체이닝하는 것이 가장 안전합니다.

### 1-4. 학생 데이터의 대표값(평균/중앙값/합계/표준편차) 1초 계산
* **사용 함수**:
  * 평균: `\operatorname{mean}(L)`
  * 중앙값: `\operatorname{median}(L)`
  * 합계: `\operatorname{total}(L)`
  * 표본표준편차: `\operatorname{stdev}(L)` / 모표준편차: `\operatorname{stdevp}(L)`
  * 원소 개수: `\operatorname{length}(L)`

## 2. 정렬 및 1위/순위 추출 (다중 키 정렬과 argmax)

### 2-1. 다른 리스트의 값을 기준으로 정렬하기 (다중 키 sort)
* **핵심 기능**: "학생 이름 번호 목록 `A`를 점수 목록 `B` 기준으로 오름차순/내림차순 정렬"
* **문법**: `\operatorname{sort}(A, B)`
* **동작 원리**: $A$와 $B$의 길이가 같을 때, $B$의 원소 크기 순서대로 $A$의 위치를 재배열합니다.
* **실전 예시**:
  ```latex
  # 학생 번호
  Students = [1, 2, 3, 4]
  # 학생 점수
  Scores = [85, 95, 70, 90]

  # 점수 순으로 학생 번호 정렬
  RankedStudents = \operatorname{sort}(Students, Scores)  # 결과: [3, 1, 4, 2]
  ```

### 2-2. 최댓값/최솟값을 기록한 학생의 인덱스(번호) 즉시 찾기
* **사용 함수**: `\operatorname{argmax}(L)` / `\operatorname{argmin}(L)` (내부 고속 바인딩) 또는 표준 수식 조합
* **표준 수식 대체법**:
  ```latex
  # L의 최댓값을 가진 인덱스를 표준 문법으로 찾기
  bestIndex = \operatorname{sort}([1...\operatorname{length}(L)], L)[\operatorname{length}(L)]
  ```
* **CL 연계 팁**: 교사 대시보드나 학생 피드백 화면에서 "이번 라운드 최고 득점 조는 X조입니다!"를 표시할 때 최고점수의 인덱스를 추출하는 데 결정적 역할을 합니다.

### 2-3. 상위 K개 값만 슬라이스하기
* **문법**: `L[start...end]`
* **실전 예시**:
  ```latex
  L_{sorted} = \operatorname{sort}(Scores)
  # 상위 3개 점수 추출 (끝에서 3개)
  Top3 = L_{sorted}[\operatorname{length}(L_{sorted})-2 ... \operatorname{length}(L_{sorted})]
  ```

## 3. 좌표 분해, 벡터 연산 및 거리/중점 계산

### 3-1. 점(Point)에서 X좌표, Y좌표 각각 분해하기
* **문법**: `P.x`, `P.y`
* **실전 예시**:
  ```latex
  P = (3, 7)
  x_0 = P.x    # 3
  y_0 = P.y    # 7
  ```
* **점 리스트 분해**:
  ```latex
  Points = [(1, 2), (3, 5), (4, 1)]
  AllX = Points.x   # [1, 3, 4]
  AllY = Points.y   # [2, 5, 1]
  ```

### 3-2. 점끼리 더하고 빼는 벡터 연산 및 중점 구하기
* **점 덧셈/뺄셈 지원**: Desmos는 점끼리의 덧셈/뺄셈을 공식 지원합니다!
  ```latex
  A = (1, 2)
  B = (5, 6)
  C = A + B       # (6, 8)
  Mid = (A + B) / 2  # (3, 4) - 중점
  ```
* **전용 내장 함수**:
  ```latex
  Mid = \operatorname{midpoint}(A, B)
  Dist = \operatorname{distance}(A, B)
  ```
  피타고라스 정리 공식 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$을 길게 쓸 필요 없이 `distance(A, B)` 하나로 완벽하게 계산됩니다.

## 4. 다각형(Polygon) 렌더링 및 다중 도형 끊어 그리기

### 4-1. 점들을 이어 색칠된 다각형 만들기
* **사용 함수**: `\operatorname{polygon}(...)`
* **문법**:
  1. 개별 점 나열: `\operatorname{polygon}((0,0), (4,0), (2,3))`
  2. 점 리스트 전달: `\operatorname{polygon}(Points)`
  3. X좌표 리스트와 Y좌표 리스트 전달: `\operatorname{polygon}([0, 4, 2], [0, 0, 3])`
* **효과**: 테두리 선뿐만 아니라 내부 영역이 반투명하게 자동으로 채워지며, 드래그 가능한 점과 연동하면 실시간으로 면적이 변하는 인터랙티브 도형이 완성됩니다.

### 4-2. [초고급 트릭] 선을 떼고 여러 도형을 수식 하나로 그리기 (`[][1]` 끊기)
* **문제 상황**: 사각형 2개를 그리고 싶은데 `polygon` 수식을 2개 쓰지 않고 하나의 수식/리스트로 처리하고 싶을 때
* **해결법**: `[][1]` (빈 리스트의 1번 원소 = undefined)을 점 사이에 삽입하면 펜을 떼고 다음 도형으로 건너뜁니다!
* **문법**:
  ```latex
  # 삼각형 1: (0,0) -> (1,0) -> (0,1)
  # 삼각형 2: (4,0) -> (5,0) -> (4,1)
  Break = ([][1], [][1])
  TwoPolygons = \operatorname{polygon}([(0,0), (1,0), (0,1), Break, (4,0), (5,0), (4,1)])
  ```
* **활용처**: 바둑판 격자, 다중 장애물 블록, 분리된 영역 렌더링 시 그래프 식의 개수를 극적으로 줄여줍니다.

## 5. 정답/오답에 따른 동적 색상 및 시각 피드백

### 5-1. `rgb()` 함수를 조건문과 결합하여 실시간 색상 변경하기
* **사용 함수**: `c = \operatorname{rgb}(R, G, B)`
* **실전 예시 (정답이면 초록, 오답이면 빨강, 미입력이면 회색)**:
  ```latex
  # isCorrect: CL에서 넘겨받는 1(정답), 0(오답), -1(미입력) 변수
  R_{col} = \{isCorrect = 1: 34, isCorrect = 0: 220, 150\}
  G_{col} = \{isCorrect = 1: 170, isCorrect = 0: 50, 150\}
  B_{col} = \{isCorrect = 1: 70, isCorrect = 0: 50, 150\}

  dynamicColor = \operatorname{rgb}(R_{col}, G_{col}, B_{col})
  ```
* **수식 적용**: 그래프 내의 점이나 도형의 Color 설정에서 `dynamicColor`를 지정하면 학생의 입력 상태에 따라 화면 색상이 즉시 반응합니다.

### 5-2. `hsv()`를 이용한 무지개/진척도 색상 그라데이션
* **문법**: `\operatorname{hsv}(hue, saturation, value)`
* **실전 팁**: `hue`는 $0 \sim 360$도의 색상환입니다.
  학생의 점수 비율 $p$ ($0 \sim 1$)에 따라:
  ```latex
  # 0도(빨강) -> 120도(초록) 부드러운 진행바 색상
  scoreColor = \operatorname{hsv}(p \cdot 120, 0.8, 0.9)
  ```

## 6. 수치 비교, 자리수 제어 및 오차 허용 채점

### 6-1. 반올림 자리수 지정 (`round`의 숨은 2인자 기능)
* **Desmos 특화 기능**: Desmos의 `round`는 **소수점 자리수를 두 번째 인자로 지원**합니다!
* **문법**:
  ```latex
  \operatorname{round}(3.141592, 2)   # 3.14
  \operatorname{round}(3.141592, 4)   # 3.1416
  \operatorname{round}(123456, -3)    # 123000 (백의 자리 반올림)
  ```
* **활용처**: 복잡한 수치 계산 액티비티에서 부동소수점 오차 때문에 채점이 오답 처리되는 것을 방지하기 위해 `round(ans, 2) = round(target, 2)`로 완벽 판정합니다.

### 6-2. 주기 함수나 반복 패턴을 만드는 나머지 연산 (`mod`)
* **문법**: `\operatorname{mod}(x, y)`
* **성질**: $x - y \cdot \lfloor x / y \rfloor$
* **실전 예시**:
  * 시계 바늘 각도: `\operatorname{mod}(hour, 12)`
  * 바둑판 패턴: `\operatorname{mod}(x, 2) = 0`

### 8-1. 학생이 입력한 수식 $f(x)$의 도함수 자동 생성
* **CL 연계**:
  ```text
  # 학생의 수식 입력을 그래프의 함수 f로 주입
  function("f"): simpleFunction(input.latex)
  ```
* **그래프 내부 수식**:
  ```latex
  # 도함수를 즉시 그래프로 표시
  y = f'(x)

  # 점 (a, f(a))에서의 접선 방정식 자동 렌더링
  y - f(a) = f'(a)(x - a)
  ```
* **실전 효과**: 학생이 어떤 다항함수나 삼각함수를 입력하더라도, 별도의 미분 계산 코드 없이 Desmos 엔진이 수치 미분/도함수를 실시간으로 그려냅니다.

## 9. 방정식 수치해 자동 계산 (회귀식의 마법)

### 9-1. 대수적으로 풀기 어려운 방정식의 교점을 그래프 스스로 풀게 하기
* **문제 상황**: 곡선 $f_1(x) = x - 3\cos(x)$가 $0$이 되는 근 $x_c$를 구하고 싶은데 CL에는 수치해석 솔버가 없음.
* **해결법**: Desmos의 회귀 연산자 `~`를 이용해 **방정식 솔버**로 활용!
* **수식 작성법**:
  ```latex
  f_1(x) = x - 3\cos(x)
  # 회귀식: f_1(x_c)가 0에 가장 가까워지는 x_c를 찾아라!
  f_1(x_c) \sim 0

  # 구한 근을 점으로 표시
  (x_c, 0)
  ```
* **효과**: Desmos 엔진의 최적화 알고리즘이 가동되어 $x_c$의 근삿값을 순식간에 역산해 냅니다.

## 10. 리스트 내포식(Comprehension)과 조별 aggregate 축약 패턴

### 10-1. 리스트 내포식 (List Comprehension: `for` 문법)
* **문법**: `[수식 for 변수 = 리스트]`
* **실전 예시**:
  ```latex
  # 1부터 5까지 점 찍기
  Points = [(t, t^2) for t = [1...5]]

  # 2차원 점 격자(Grid) 생성 (내포 루프)
  Grid = [(x, y) for x = [1...5], y = [1...5]]
  ```

### 10-2. 조별 aggregate 데이터에서 조별 대표값 한 줄 축약 (최고급 패턴)
* **상황**: CL의 `aggregate`로 전교생의 조 번호 리스트 $G$와 제출 값 리스트 $N$이 들어옴.
* **조별 최댓값 6개 한 번에 추출**:
  ```latex
  GroupMax = [\operatorname{max}(\operatorname{join}(N[G = j], 0)) for j = [1...6]]
  ```
* **해설**:
  1. `G = j`: $j$번 조에 속한 학생들의 인덱스만 필터링
  2. `N[G = j]`: 해당 조 학생들의 제출값 리스트
  3. `join(..., 0)`: 만약 그 조가 아직 아무도 제출 안 했으면 빈 리스트가 되므로 `0`을 덧붙여 에러 방지
  4. `max(...)`: 그 조의 최댓값 선정
  5. `for j = [1...6]`: 1조부터 6조까지 6개의 대표값을 단 1줄로 완성!
